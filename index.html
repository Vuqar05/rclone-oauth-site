rclone-vugar

rclone-vugar is a personal-use configuration of rclone, the open-source command-line tool for managing and syncing files across cloud storage providers. This instance is used by a single individual to keep files synchronized between their own local device and their own Google Drive account — for example, backing up a local folder to Drive, mirroring a Drive folder locally, or moving files between the two from the command line.

What this app does

  • Lists, uploads, downloads, renames, moves, and deletes files and folders in the user's own Google Drive, as directed by rclone commands the user runs locally.
  • Compares file metadata (size, checksum, modified time) between the local device and Google Drive to perform efficient, incremental sync operations.
  • Runs entirely on the user's own device — there is no hosted server, backend, or web service associated with this app.

Why it requests access to your Google data

To do the above, this app requests Google OAuth scopes for Google Drive file access (drive), read-only Drive metadata (drive.metadata.readonly), and read-only Google Docs metadata (docs), so it can find, compare, and transfer files during sync operations. It does not request any data beyond what these file-sync features need, and it does not use your data for advertising, sell it, or share it with third parties.
